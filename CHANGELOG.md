# Changelog

## 1.0.1
- Added a setting to choose whether the clock is moved to the left side
  (enabled by default), with a preferences window.
- The setting applies immediately, without restarting GNOME Shell.
- Prepared for public release: schema and metadata follow the GNOME Shell
  extension review guidelines, unnecessary checks and comments removed, and a unique GType
  name is used for the layout constraint.
- Updated supported versions to GNOME Shell 48, 49 and 50.

## 1.0.0
- Initial release.
